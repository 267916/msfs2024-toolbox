微软2024工具箱 —— 使用说明
==============================

MSFS2024 相关工具的下载器客户端：
下载 → 自动解压 → 卡片上出现「启动」，点击直接运行对应程序。
自动检测各项目的最新版本（GitHub）和本地已装版本，有新版时提示更新。

  ① AMDB Bridge 中文壳      已发布   启动 AMDB-ZH.exe
  ② A350 座舱与 EFB 汉化    已发布   启动 A350座舱中文.exe
  ③ A350 语音副驾驶         待发布（接口已预留）

版本检测怎么工作
----------------
最新版本：启动工具箱后自动向 GitHub 查询各项目的最新 Release 标签。
本地版本：工具箱下载解压时会把版本写进 downloads\{项目}\version.txt。
两者不一致时卡片显示「↑ 有新版本 vX.X，点更新」，按钮变为「更新」。

本机已有副本检测
----------------
即使不是用工具箱下载的，启动时也会自动检测：
  · downloads 里已有压缩包但没解压 → 自动解压，直接可用
  · 工具目录 / 桌面 / 用户"下载"文件夹里已有主程序（如手动解压过）
    → 卡片显示「✓ 检测到本机已有副本」，按钮直接是「启动」
版本无法确定时显示"未知"，点一次「重新下载」即可对齐。

机模状态（卡片第二行）
----------------------
· A350 座舱与 EFB 汉化：显示「机模内汉化：已应用 / 未应用」——
  已应用 = 翻译已写入机模，进游戏即生效；未应用 = 启动应用器写入即可
· AMDB Bridge 中文壳：显示「AMDB 本体：已安装 / 未安装」——
  壳需要本体才有意义，未安装时先去装 AMDB Bridge

用法
----
双击 微软2024工具箱.exe：
  · 「下载」→ 进度条走完自动解压 → 按钮变「启动 xxx.exe」→ 点击直接运行
  · 已下载的项目下次打开直接显示「启动」
  · 有新版本时显示「更新」，点击重新下载最新版
  · 「重新下载」：清掉旧的压缩包和解压目录重新来（程序开着会删不掉，关掉再点）
文件都在 exe 旁的 downloads\ 里，每个项目一个子文件夹。

给语音副驾驶预留的接口
----------------------
等它上了 GitHub，用记事本打开本目录的 links.txt，填上这两行、保存、
重启工具箱即可（不需要重新编译）：

  copilot=下载直链
  copilot_home=项目主页

直链格式（GitHub Release 直链写法）：
  https://github.com/仓库主/仓库名/releases/latest/download/附件名.zip
注意：出了新版本要同步更新这里的附件名（例如 v1.1.zip → v1.2.zip），
否则会 404；同时发一个新 Release（tag 如 v1.2），工具箱就能自动提示更新。

其他
----
· 命令行 --selftest       ：不弹窗，打印链接可用状态 + 最新/本地版本
· 命令行 --get amdb|efb    ：无窗完整测试 下载→解压→定位主程序
· 崩溃日志：toolbox-crash.log（exe 旁，仅异常时产生）
· 完全本地运行，除下载和版本查询（GitHub API）外不联网，不上传任何信息
· 源码 A350Toolbox.cs，编译（源码必须存成 UTF-8 带 BOM）：
  C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
    /nologo /target:winexe /codepage:65001
    /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll
    /out:微软2024工具箱.exe A350Toolbox.cs
