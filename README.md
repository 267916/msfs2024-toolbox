# 微软2024工具箱

MSFS2024（微软模拟飞行 2024）相关工具的下载器客户端：打开后点「下载」，自动解压，再点「启动」直接运行。自动检测各项目的最新版本与本地版本，有新版会提示更新。

**本仓库不包含任何第三方软件本体**——工具箱只负责从各项目官方 Release 下载。

## 使用

1. 从本页 **Release** 下载 `MSFS2024-Toolbox-vX.X.zip`，解压到任意文件夹
2. 双击 `微软2024工具箱.exe`（无需安装，Windows 10/11 系统自带 .NET 即可运行）
3. 点卡片上的「下载」→ 等自动解压完成 → 点「启动 xxx.exe」

下载与解压都在工具箱旁的 `downloads\` 文件夹里，每个项目一个子文件夹，删除工具箱文件夹即可完全卸载。

## 直链与更新

工具箱读取同目录的 `links.txt` 获取下载直链，可以直接编辑（格式见文件内注释）。
工具箱本身也会通过 GitHub 检测各项目的最新版本并提示更新；出了新版本时，
把 `links.txt` 里的附件名改成新版号即可（例如 `...v1.2.zip` → `...v1.3.zip`）。

## 自检

命令行运行 `微软2024工具箱.exe --selftest` 可以无窗打印三条链接的可用状态与版本，
`--get amdb|efb` 可以无窗完整测试"下载→解压→定位主程序"。
